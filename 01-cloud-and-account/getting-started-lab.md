# Lab: Getting Started with AWS

This lab follows the guide [Getting Started with AWS](https://www.yuval.guide/aws/01-cloud-and-account/aws-getting-started/)
on yuval.guide, which shows every screen of it.

- The lab opens an AWS account and signs in to it as the root user.
- It ends with the console's start page, Console Home, on the screen.

## Get an AWS account

<details>
<summary>Option 1: you have no AWS account</summary>

1. Follow the guide's step [Open an AWS account](https://www.yuval.guide/aws/01-cloud-and-account/aws-getting-started/#open-an-aws-account).
2. Wait for AWS's email saying the account is active.

</details>

<details>
<summary>Option 2: you already have an AWS account</summary>

1. Find the account's root email address and password.
   - The course signs in as the root user in this session.

</details>

## Sign in as the root user

1. Follow the guide's step [Sign in as the root user](https://www.yuval.guide/aws/01-cloud-and-account/aws-getting-started/#sign-in-as-the-root-user).

## Check the console

1. Check that the page is headed **Console Home**.
2. Check that the console's top bar holds the search bar.
